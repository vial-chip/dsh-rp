# @deepseek-ai/dsh-client-ui-roleplay

[English](README.md) | 中文

## 概述

在原生输入框旁选择角色，并在右侧栏查看固定的角色设定。独立书签分别显示已保存的世界、身体、服饰和数值关系状态。逐项编辑状态不会请求模型回复。撤销会把最近一轮互动的文字放回输入框；重新生成会复用原始输入。

<a id="use-this-package"></a>
## 使用本包

角色扮演控件复用现有会话输入框和右侧栏。仅当会话具有角色扮演状态时，输入框控件才会显示。角色卡有说明时优先显示说明，并在浏览器偏好中记住上次选择的技能名称。角色卡书签会在首次互动前预览所选设定，不会固定其内容。首次互动被接受时固定角色卡内容；之后修改文件不会替换该会话的设定。

### 配置

宿主入口公开浏览器插件。将 `@deepseek-ai/dsh-client-ui-roleplay` 与原生会话、右侧栏、语言、远程服务和宿主 Roleplay 服务一起挂载。本包没有配置字段。

### 已保存状态与互动操作

打开状态书签会读取会话投影。编辑只写入选定类别和字段；关系编辑直接设置绝对数值。编辑失败时保留已保存值和编辑草稿。只有模型自主通过工具读取对应状态时，人工编辑才会提供给模型。

会话空闲时可以撤销或重新生成。撤销将文字放回原生输入框，等待用户发送。撤销继续操作不会改变输入框。重新生成通过宿主服务重新提交包含附件的原始消息。宿主负责撤回历史和恢复状态，并保留后续人工编辑。

### 应用级工具开关

角色卡书签的工具区提供八个独立的原生插件开关。每个开关通过插件管理器写入应用配置补丁，对所有角色扮演会话生效；普通模式不暴露这些工具。部署未启用实时配置重载时会提示需要重启。打开这些设置不会请求模型回复。

## 理解实现

<details>
<summary>实现细节——点击展开</summary>

浏览器入口贡献一个输入框控件、五种原生右侧栏书签和宿主持有的操作结果提示。展示组件接收普通回调和框架绑定的投影钩子。远程操作保留在浏览器入口；持久化的角色卡和状态值来自 Roleplay 投影。加载和查询失败在角色卡选择器旁显示；临时操作结果使用外壳覆盖层。

<a id="model-experience"></a>
## 模型体验

无，因为此浏览器界面不注册面向模型的工具或消息；Roleplay 负责模型可见行为。

#### KV Cache effect

无。打开书签和保存人工编辑不会增加模型输入。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 撤销仅恢复文字。原生输入框没有从持久化附件引用恢复草稿的操作；重新生成在宿主保留原始消息附件。
- 模型读取对应状态前，面板保存值可能与叙事不同。叙事文本不会更新这些面板。
- 角色扮演自有界面文案始终为中文，包括应用语言为英语时。
