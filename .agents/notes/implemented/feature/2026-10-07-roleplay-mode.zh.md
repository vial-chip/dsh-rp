# Agent Note: 共享角色记忆的角色扮演模式

Status: implemented

[English](2026-10-07-roleplay-mode.md) | 中文

## Problem

日常陪伴需要稳定的人物塑造，以及开始新会话后仍可使用的精选记忆。共享场景状态会阻碍独立场景；为每个会话分别保存记忆会阻碍持续关系。工作工具、工作目录和工作历史不属于这种体验。

## Decision

第五个内置预设通过现有 Web 和 Desktop 组合支持一位玩家与一位主要 AI 角色。角色可以描述环境并扮演偶然出现的人物；玩家控制自己的对话、决定和内心体验。[领域术语](../../../../CONTEXT.md) 区分角色卡、独立档案、共享记忆和会话场景。

### 所有权与持久化写入

[角色服务](../../../../packages/roleplay/roleplay/README.zh.md) 拥有独立存储域。档案绑定捕获的本地技能格式角色卡，并拥有玩家设定、共享记忆、数值关系指标和多个独立会话场景。同一角色卡创建的档案不共享记录。部署容量限制属于经过验证的配置；超过限制会拒绝整次写入。

每次变更通过存储域原子发布完整档案、修订快照与冲突。带品牌类型的档案、角色卡版本、记忆和操作标识保留所有权。模型操作指定会话、回复和预期修订；重复操作标识不会再次生效。中断回复保留已经提交的操作；撤销显式补偿这些操作。

场景字段描述 AI 角色与当前环境。玩家身份与 AI 角色的身体、服饰和临时情绪分开保存。会话共享记忆与关系指标，而不共享场景字段或完整历史。模型关系更新接受限幅增减量；用户编辑接受绝对值。修订保留实际生效的限幅增减量，以便选择性补偿。

### 已记录上下文与纠正

每次模型请求通过已记录的动态上下文接收绑定角色卡、当前档案修订、玩家、会话场景、数值关系与精选记忆。读取和更新工具执行档案所有权检查并验证模型 JSON。角色模式提供自己的角色卡与工具，排除工作技能和工具，且没有工作目录。工作导航与历史检索排除角色 Session；应用共用模型设置仍然可用。

过时模型写入将提议保留为可见冲突，同时保留当前值。手动编辑场景、玩家、关系和记忆属于管理操作，而不是虚构对话。对应检查点标识已经提交的档案修订，后续请求接收纠正后的数据。历史记录中的请求保留当时收到的信息。

每条记忆保留来源会话、回复与证据消息。用户纠正保护被修改的条目，避免与其冲突的模型推断覆盖它。作废保留记忆，以及按证据和稳定记忆键索引的删除标记，阻止从同一来源自动重新提取。归档会话保留其共享记忆。

### 角色卡与历史操作

编辑源角色卡不会改变已有档案。显式应用角色卡更新该档案各会话的未来请求，保留历史定义，并将有效记忆标为待复核。场景字段保留同名值，新增字段使用角色卡初值；指标保持在所应用角色卡的范围内。

必需的 Session 检查点标识不可变档案修订与会话场景。初始化、模型请求、工具更新和管理编辑后都有检查点。分支解析所选日志位置的修订，并以该会话场景创建独立档案。分支不会解析源档案当前状态，也不会提交新回复。已发布 Session 代际保持不变；不认识检查点事件的构建拒绝包含该事件的日志。

撤销只接受最近一次已完成、由当前会话拥有的回复，并拒绝尚未处理的排队输入。操作追加补偿档案修订，根据先前历史创建替代 Session，并归档原会话。后续用户赋值与其他会话的无关贡献保留；依赖变更成为冲突。重生成只提交一次原玩家输入。非法历史更新路径或缺失关系增减量会在发布前拒绝补偿。

跨服务生命周期操作在变更档案或 Session 数据前，将标识保存在持久化恢复意图中。恢复重复执行幂等写入，创建或恢复同一个子 Session，刷新检查点，并完成归档后再移除意图。待完成操作阻止档案推进。启动恢复与历史分支不会生成对话；只有玩家输入或显式继续会推进场景。

## Alternatives considered

**为所有会话共享一个场景。** 否决，因为不同会话需要独立的时间、地点、服饰和临时情绪，同时共享关系发展。

**为每个会话分别保存记忆。** 否决，因为开始另一个场景必须保留档案的持续关系与精选经历。

**一个反复改写的记忆段落。** 否决，因为纠正、冲突更新和选择性撤销需要可识别的条目、来源与修订。

**每个会话分别绑定角色卡版本。** 否决，因为共享同一档案记忆的会话需要一致的人物塑造；显式档案更新保留历史定义。

**规则模拟与离线推进。** 延后，因为该体验优先考虑日常对话、模型维护的一致性与玩家控制的场景推进。

## Consequences

独立档案与修订快照使纠正、历史分支和选择性撤销可供检查。保留完整修订与绑定角色卡正文占用存储；部署限制约束每个档案，并原子拒绝超限写入。

记忆提取与叙事一致性依赖模型判断。证据与时间限定支持纠正，但不保证回忆。共享关系发展约束独立场景；不兼容的历史需要协调或使用独立档案。撤销无法逆转已经在其他场景叙述的后果。

作废将事实排除在有效记忆之外，但不会抹除历史对话。归档保留共享记忆，不会永久删除 Session 数据。新档案提供独立起点。角色卡通过文件编辑；冒险规则、专用角色卡编辑器和任意历史回滚不属于本决策。

## Verification

定向行为与界面测试覆盖独立所有权、重启持久性、共享记忆、过时写入、用户纠正、作废、选择性补偿、精确历史分支与 Session 写入失败后的恢复。新增角色与界面源码满足逐文件 100% 覆盖率要求。随附 Web 会话记录场景与两种 SDK 预期输出保留必需检查点事件。

真实 DeepSeek 对话通过角色工具写入偏好与关系变更。管理面板对服饰和信任的纠正进入下一次已记录请求，浏览器刷新保留纠正后的档案与带证据的记忆。第二个会话回忆共享的周日做饭约定与茉莉花茶，同时保留第一个场景已纠正的服饰。截图保留已经验证的 GUI 状态；按用户要求省略 GIF 编码。
